Notes:
- 04_exploratory_data_analysis.ipynb is used for manuscript data analysis and visualization and can be run after 03_build_modeling_dataset.ipynb.
- MPNN特征预训练_粘度_折内无泄露版.ipynb is a helper notebook called by 07_generate_outer_fold_mpnn_features.ipynb and does not need to be run separately.
- Only Data_split and IL_split are used for the model evaluation and results reported in this manuscript.
- Intermediate molecular-graph files generated by 05_build_mpnn_graphs.ipynb are not stored in the repository and can be regenerated by running that notebook.
